# JetBrains Mono

Tipografía embebida en el PDF del informe («Informe técnico») para que el
documento use la misma fuente que la interfaz de la aplicación.

- **Fuente:** JetBrains Mono — https://www.jetbrains.com/mono/
- **Autores:** JetBrains (JetBrains s.r.o.)
- **Licencia:** SIL Open Font License 1.1 (OFL-1.1)
  https://scripts.sil.org/OFL

Los archivos `JetBrainsMono-Regular.ttf` y `JetBrainsMono-Bold.ttf` se usan
tal cual, sin modificar, tal como permite la OFL.
